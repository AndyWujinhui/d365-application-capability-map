# Dynamics 365 Application Capability Map

An interactive bilingual dashboard covering the Dynamics 365 application portfolio, end-to-end ERP processes, Power Platform, Copilot Studio, and Jack Wolfskin landscape coverage.

## Features

- Chinese and English presentation modes
- Fullscreen presentation and slide navigation
- Dynamics 365 CRM and ERP portfolio architecture
- Seven application capability deep dives
- End-to-end process matrix
- Jack Wolfskin system landscape coverage mapping
